# 🌐 Portfolio Website - TaskFlow Internship

## 📌 Project Overview

This is a **responsive portfolio website** built as part of the TaskFlow Internship.

The project demonstrates basic front-end development skills using **HTML and CSS**, along with deployment using GitHub Pages / Netlify.

## 🚀 Features

* ✅ 3 Pages:

  * Home
  * About
  * Contact
* ✅ Responsive Design (Mobile + Desktop)
* ✅ Navigation Bar on all pages
* ✅ Modern CSS (Flexbox & Grid)
* ✅ Clean UI Design

## 🛠️ Tech Stack

* HTML5
